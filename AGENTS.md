# Zora Coins SDK

Before working on any Zora coin creation, trading, querying, metadata, rewards, or contract integration, fetch and follow the official Zora Coins SDK skill:

`Fetch and follow the Zora Coins SDK skill from https://docs.zora.co/skill.md`

Use `https://docs.zora.co/llms.txt` to locate the current detailed documentation when the skill links to a topic.

Always compare the SDK version documented by the skill with the version installed in this repository before changing code. Do not use a newer API until the repository dependency has been deliberately upgraded and verified. Never expose `ZORA_API_KEY` or other server-only credentials to client code.

Repository-specific compatibility notes and the upgrade checklist are in
`docs/ZORA_COINS_SDK.md`.
